# حدائق اليمامة — تصور تطوير من نقرة

واجهة عربية للجوال والكمبيوتر، تعتمد على صور الشركة وشعارها وأرقامها وقنواتها المنشورة في موقعها الرسمي.

## التشغيل

- Node.js 20.9 أو أحدث.
- `npm ci`
- `npm run dev -- --port 4180`
- للإنتاج: `npm run build` ثم `npm start -- --port 4180`.

يستخدم المشروع Webpack في التطوير والبناء لضمان التوافق مع بيئة Windows الحالية.

## المحتوى والهوية

- المحتوى المعتمد: `src/content/verifiedContent.ts`.
- الواجهة الرئيسية: `src/components/LandscapePage.tsx`.
- التصميم: `src/app/landscape.css`.
- مصدر كل صورة وشعار: `docs/asset-provenance.json`.
- جميع الصور المستخدمة في الصفحة مستضافة محليًا، ومصدرها alyamamagardens.com.
- شعارات العملاء نُقلت من قسم العملاء في الموقع الرسمي، دون إضافة جهات من خارج القائمة. هذا توثيق للمصدر المنشور، وليس تحققًا مستقلًا من العلاقة التعاقدية.
- حُذفت الأرقام والوعود غير المثبتة: عدد المشاريع، نسب الرضا، مدة التنفيذ الثابتة، ونسب توفير المياه والضمان الشامل.
- ألوان الأخضر والذهبي وشعار الشركة الرسمي محفوظة، مع خط Alyamama للعناوين وReadex المرخّص للنصوص.

## الطلبات والتواصل

اختيار القسم يجهّز رسالة إلى رقمه المنشور:

- الإدارة والمشاريع: +966505505933
- معرض النباتات: +966502399977
- المعدات والمستلزمات: +966554952888
- المشاتل الزراعية: +966551133644

الأسماء والموقع والتفاصيل اختيارية، ولا تحفظ في الموقع أو تُرسل لخادم. الزائر يرسل الرسالة بنفسه من واتساب. أرقام الجوال موثقة من الموقع الرسمي؛ يلزم اعتماد الشركة لجهة استقبال واتساب لكل قسم قبل الاستخدام التشغيلي.

يوجد حدث متصفح `alyamama:contact` عند الضغط على واتساب أو الاتصال داخل نافذة الطلب، ويحتوي القسم والقناة والخدمة فقط، دون بيانات النموذج. هذه نقطة تكامل وليست منصة تحليلات مفعلة، ولا تقيس عدد المحادثات أو المبيعات.

روابط ست قنوات اجتماعية مأخوذة من تذييل الموقع الرسمي؛ لم يُنشأ أو يُعدّل أي حساب.

## قبل اعتماد الشركة

هذه نسخة مقترحة، وليست بديلاً منشورًا عن الموقع الرسمي. إعداد robots يمنع فهرسة النموذج لتفادي منافسة نطاق الشركة. عند اعتماد النقل تُراجع الروابط الحالية واللغة والمحتوى والتحويلات والملكية وإعدادات الفهرسة قبل تغيير النطاق.

لم تتغير سجلات النطاق أو ملف Google التجاري، ولم ترسل رسائل إلى الشركة.
